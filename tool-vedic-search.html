🔭 वैदिक-अन्वेषणम् · Vedic word search

Is a word form attested — and where? Type it in ITRANS, IAST or देवनागरी. This page builds the right query for the TITUS text database (Frankfurt), which indexes the Vedic saṃhitās, brāhmaṇas, sūtras, the epics and much classical literature. The search itself runs on TITUS; nothing is sent anywhere else.

 
How this works · limits
  • Spelling. TITUS's index is romanised (IAST); a Devanāgarī or ITRANS query finds nothing there, so this page converts it. Aspirates may be typed plainly (dh matches TITUS's dʰ); vocalic ṛ is sent as TITUS spells it (r̥); accents are ignored (accented and unaccented texts both match).
  • Sandhi. vidyāt before a vowel or voiced sound is printed vidyād, before c vidyāc, before a nasal vidyān — and the index keeps these apart (exact vidyāt: 4 hits; vidyād: 306). So the query ORs all the final-sound variants together. A word whose final vowel merges with the next word (-a/-ā + vowel) cannot be found as a separate word; -i/-u/-e/-o finals are covered via their y/v/a/ay/av forms.
  • Elided a- ('vṛṇīta) is indexed under the full form, so it is found automatically.
  • Coverage. TITUS labels its retrieval engine a preliminary version: a hit it shows is real, but a count is not a frequency, and "no hit" is not proof of absence.
  • Scope. TITUS groups texts by its own "varieties"; one query searches one variety (or all Sanskrit). The examples under each scope are texts TITUS returned for it in a test query, not a full list.
  • Results open on titus.fkidg1.uni-frankfurt.de in a new tab; the server can take a minute or two.
